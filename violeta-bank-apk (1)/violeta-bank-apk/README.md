# Violeta Bank (simulador)

App de simulação bancária com dinheiro fictício. Não é um banco real.

## Gerar o APK pelo GitHub
1. Crie um repositório no GitHub e envie todos estes arquivos.
2. Abra a aba **Actions** e rode **Build APK** (ou faça um push).
3. Ao terminar, baixe o arquivo **violeta-bank-apk** em *Artifacts* e instale o .apk no celular.

O conteúdo do app fica em `app/src/main/assets/index.html`.
